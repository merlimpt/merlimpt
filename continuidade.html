Objetivo 3 · Art. 21 NIS2

Resiliência operacional e continuidade de serviço

Assegurar disponibilidade dos serviços de comunicações eletrónicas face a incidentes cibernéticos e físicos.

Objetivos de recuperação por serviço

Serviço / Sistema RTO RPO Site alternativo
Core Network (voz/dados) ≤ 4 horas ≤ 15 min DC secundário geo-redundante
5G Core (SA/NSA) ≤ 4 horas ≤ 15 min NFVI standby
BSS — Billing ≤ 8 horas ≤ 1 hora Warm standby
OSS — Provisioning ≤ 8 horas ≤ 1 hora Warm standby
DNS / Autoritativo ≤ 1 hora 0 (sincrono) Anycast multi-site
Portais cliente / Self-care ≤ 2 horas ≤ 30 min Cloud multi-AZ
NOC / SOC ≤ 1 hora N/A Sala de crise alternativa

Cenários de continuidade

Cenário Impacto Procedimento
Ransomware em BSS/OSS Billing e provisioning indisponíveis Isolar segmento, restaurar de backup offline, ativar modo degradado
Destruição de datacenter primário Core e serviços críticos offline Failover automático para DC secundário, ativar equipa de crise
Falha de fornecedor cloud Serviços digitais indisponíveis Failover para região/AZ alternativa, comunicar a clientes
Ataque DDoS massivo Degradação de conectividade Ativar scrubbing, blackhole temporário, escalar com upstream
Corte de energia prolongado Equipamentos em site afetado Geradores, UPS, redistribuição de carga

Calendário de testes

Teste Frequência Âmbito Responsável
Failover core network Semestral MSC, IMS, 5G Core Eng. Core
Restauro BSS/OSS Anual Billing, CRM, provisioning IT Ops
DR de datacenter Anual Full site failover Infra
Teste de backups Trimestral Restauro aleatório de sistemas críticos Infra + App owners
Exercício de crise integrado Semestral BCP + comunicação + regulador CISO

Requisitos de redundância

  • Redundância geográfica para todos os sistemas classificados como críticos
  • Segmentação de rede para limitar propagação lateral em caso de compromisso
  • Backups imutáveis (air-gapped ou WORM) para sistemas BSS/OSS
  • Links internacionais com diversidade de rotas e fornecedores
  • Integração do BCP com plano de gestão de crises e comunicação externa

Indicadores de sucesso

  • Testes DR anuais realizados com resultados documentados
  • RTO/RPO cumpridos nos exercícios de failover
  • Planos BCP/DR atualizados após cada teste ou incidente significativo
  • Procedimentos de emergência documentados e acessíveis 24/7
  • Comunicação com regulador e clientes integrada no plano de crise
