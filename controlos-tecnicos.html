Objetivo 6 · Art. 21 NIS2

Hardening técnico e controlo de acessos

Implementar controlos técnicos mínimos exigidos pelo Art. 21, adaptados à realidade telecom.

Autenticação multifator (MFA)

Âmbito Requisito Estado alvo
Acessos administrativos a core network MFA obrigatório (hardware token ou FIDO2) 100%
VPN corporativa MFA em todos os acessos 100%
Consolas de gestão de rede (EMS/NMS) MFA + sessão gravada 100%
Cloud (AWS, Azure, GCP) MFA para root/admin, IAM roles 100%
Portais internos (BSS/OSS) MFA para funções privilegiadas 100%
Acessos de fornecedores MFA + just-in-time access 100%

Gestão de identidades e acessos (IAM)

  • Provisioning centralizado — integração com HR para onboarding/offboarding automático
  • Revisão de privilégios — trimestral para contas admin, semestral para restantes
  • Contas de serviço — inventariadas, com passwords rotacionadas e sem login interativo
  • Separação de funções — quem desenvolve não faz deploy em produção
  • Zero credenciais partilhadas — contas individuais com rastreabilidade

Encriptação

Dados Em trânsito Em repouso
Dados de subscritores (PII) TLS 1.2+ / IPSec AES-256
Sinalização (SS7/Diameter) IPSec / TLS onde suportado N/A
Backups N/A AES-256, chaves geridas em HSM/KMS
Comunicações de equipa de crise E2E encrypted (Signal, etc.) N/A
Logs e telemetria TLS para envio a SIEM Encriptação em storage

Segmentação de rede

Zona Sistemas Controlos
Core Telecom (OT) MSC, HLR, IMS, 5G Core Isolamento físico/lógico, firewall dedicado, sem internet direta
BSS/OSS (IT) Billing, CRM, provisioning VLAN dedicada, acesso via jump server
DMZ Portais, APIs, proxies WAF, rate limiting, IDS/IPS
Corporate IT Estações, email, ERP Segmentação por departamento, EDR
Cloud Workloads em hyperscaler VPC/VNet isoladas, security groups, microsegmentação

Higiene cibernética

Controlos Descrição SLA
Patch management Atualizações automáticas para OS e apps; janelas para equipamentos de rede Crítico: 72h; Alto: 30d
Gestão de vulnerabilidades Scanning mensal, priorização por CVSS e exposição Relatório mensal
Hardening CIS benchmarks para OS; guias de fornecedores para equipamentos de rede Anual
EDR/XDR Agentes em todos os endpoints corporativos e servidores BSS/OSS 100% cobertura
Desativação de serviços Portas e protocolos desnecessários desativados Contínuo

Indicadores de sucesso

  • MFA em 100% dos acessos privilegiados
  • MTTR de patches críticos dentro do SLA definido (≤72h)
  • Zero credenciais partilhadas em produção
  • Revisão de privilégios trimestral concluída e documentada
  • Segmentação IT/OT implementada e testada
  • EDR/XDR com cobertura ≥95% dos endpoints
